# Power Transformation Using Box-Cox and Yeo-Johnson

## Project Overview
This project focuses on Power Transformation techniques used in data preprocessing to make data more normally distributed and reduce skewness.

Two transformation techniques are implemented:
- **Box-Cox Transformation**
- **Yeo-Johnson Transformation**

## Objectives
- Understand the concept of Power Transformation.
- Reduce skewness in numerical features.
- Improve data distribution.
- Compare Box-Cox and Yeo-Johnson transformations.
- Visualize data distributions before and after transformation.

## Techniques Used

### 1. Box-Cox Transformation
- Used to reduce skewness in data.
- Works only with strictly positive values.
- Helps stabilize variance and improve normality.

### 2. Yeo-Johnson Transformation
- Similar to Box-Cox transformation.
- Supports both positive and negative values, including zero.
- Useful for handling a wider range of numerical data.
